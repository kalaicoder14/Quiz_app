# 🧠 Quiz App

A simple and responsive **Quiz Application** built using **HTML, CSS, JavaScript, and Bootstrap 5**. Users can answer multiple-choice questions, manage their time, and view their final score.

## 🚀 Live Demo

🔗 **Live Demo:https://quiz-app-bice-one.vercel.app/

## 📌 Features

* 📝 Multiple-choice questions
* ⏱️ 30-second timer for each question
* 📊 Dynamic progress bar
* ✅ Instant answer validation
* ❌ Displays incorrect and correct answers
* 🏆 Final score calculation
* 📈 Percentage calculation
* 🔄 Restart quiz option
* 📱 Fully responsive design
* 🎨 Modern and clean user interface
* 📚 10 web-development questions

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Quiz logic, timer, score calculation, and DOM manipulation
* **Bootstrap 5** – Responsive layout and UI components

## 🎮 How to Play

1. Open the Quiz App.
2. Click the **Start Quiz** button.
3. Read each question carefully.
4. Select one of the four options.
5. You have **30 seconds** to answer each question.
6. Click **Next Question**.
7. After completing all questions, your final score will be displayed.
8. Click **Restart Quiz** to play again.

## 🧩 Quiz Flow
